# Palette Vault

## What it is
Palette Vault is a web app where users can discover, share, and save custom color palettes with real-time visual previews.

## Who it's for
Who adds things:
Designers, artists, and creators who want to share their custom color combinations with others.

Who opens it just to look, and why:
A digital artist or graphic design student working on a project or website who is stuck on a color scheme and wants to see side-by-side visual swatches, category vibes, community favorites, and fresh inspiration.

## The table
What one row is:
One saved color palette containing a title, creator name, tags, category, custom colors, and likes.

| column | kind | notes |
|---|---|---|
| title | typing | Text input for palette name (e.g., "Mushroom Kingdom") |
| creator_name | typing | Text input for creator name (e.g., "Alex") |
| tags | typing | Text input for search terms (e.g., "mario, retro, gaming") |
| category | pick from a list | Dropdown selection for the overall vibe |
| colors | dynamic pick | Array/list of hex codes generated by HTML color pickers |
| likes | number | Automatically starts at 0, updated when users click Like |

The pick-from-a-list column is category and the choices are Pastel, Minimal, Neon, Dark, and Vibrant.

## The two views
The adding view:
A form view where creators type a title, creator name, and tags, select a category from a dropdown, and pick 3 to 10 visual colors using HTML color pickers to submit a new palette.

The looking view:
An Explore view displaying saved color palettes as visual swatch cards, equipped with category filtering, sorting options, a keyword search bar, and interactive Like buttons.

What the looking view tells you that the raw list doesn't:
It shows side-by-side visual color harmony, curated category vibes, community-validated favorites via like counts, and dynamic search results instead of a plain text list of color names.

## Three things it does with the saved rows
1. Filter by Category: Filters palette cards to show only palettes matching a selected category (possible because of the category column).
2. Sort by Likes or Date: Reorders all saved palettes by highest likes count or newest addition date (possible because of the likes and added_at columns).
3. Search by Tags or Title: Dynamically searches through palette keywords and names (possible because of the tags and title columns).

## The awkward cases
Nothing saved yet:
Displays an empty-state message inside the list view saying: "No color palettes saved yet! Be the first to create one."

Empty submit:
Uses HTML required attributes on inputs so the browser blocks submission and displays a "Please fill out this field" warning if any field is blank.

500 characters:
Uses HTML maxlength attributes on text inputs (e.g., title maxlength="40", creator_name maxlength="25", tags maxlength="60") to prevent typing past the limit.

300 rows:
Applies query settings (like .limit(20)) to pull 20 items at a time, rendering palette cards in a clean vertical grid that the browser can naturally scroll through.

## NOT doing, on purpose
- User sign-in, accounts, or passwords (by Asfa)
- Editing or deleting saved palettes after submission (by Asfa)
